# Mid-Town Motel: retro redesign

A static, dependency-free redesign of the Mid-Town Motel site (Boothbay Harbor, Maine): a calm 1950s motor-lodge look, a mobile-first layout and all content taken from the original site.

**Pages:** Home, Rooms, About, Offers, Boothbay Guide (things to do + local eats), Location, Policies, Photo Tour, 404.

**Look:** calm retro motor-lodge style (cream, navy, teal, coral), real photos from the original site, one gentle fade-in on scroll, mobile menu, photo lightbox and a sticky Call / Book bar on mobile. Respects `prefers-reduced-motion`.

## Run locally
Open `index.html` in a browser, or:
```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Put it on GitHub and publish (GitHub Pages)
```bash
cd midtown-motel
git init
git add .
git commit -m "Initial commit: Mid-Town Motel redesign"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```
Then on GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `(root)` → Save.**
The site appears at `https://<your-username>.github.io/<repo-name>/` after a minute. `.nojekyll` is included so files are served as-is.

## Editing content
Pages are generated by `build.py` so that header, footer and copy stay consistent.
1. Edit the data blocks at the top of `build.py` (rooms, amenities, guide, eats, policies, phone, booking URL).
2. Run `python3 build.py` to regenerate the `.html` files.
3. Commit and push.

Styles are in `assets/css/style.css` (colors are CSS variables at the top). Behavior is in `assets/js/main.js`.

## Photos
Photos are the ones from the original site and are loaded directly from `midtownmaine.com` (see the `IMG`, `ROOM_IMGS` and `GALLERY` lists in `build.py`). They only show while the original site is online.

To host them yourself: save each image into `assets/img/`, change the URLs in those lists to local paths such as `assets/img/home-hotel-hero.jpg`, run `python3 build.py`, and push. Keep each photo under about 300 KB for fast loading. If a photo fails to load, a colored placeholder is shown instead.

## Things to confirm with the client
- **Booking link:** uses the existing ResNexus link from the original site (`BOOK_URL` in `build.py`).
- **Domain:** `SITE_URL` in `build.py` is set to `https://midtownmaine.com`. Update it if the site is hosted elsewhere.
- **Years in business:** the original says both "66 years" and "70+ years", so this version says "1950s roots" instead.
- **"Two Twins" room:** the original tags it "King" even though the name says two twins. This version shows two twin beds.
- **Whole Property:** the original lists no capacity or bed details, so none are shown.
- **Original site's lighthouse link** pointed to an unrelated Italian restaurant site, so it is left without a link.
- **Privacy and Accessibility pages** exist on the original site but were not rebuilt here. Add them before going live.
- Room-detail pages and the booking engine are not included; booking buttons go to ResNexus.

This is a concept redesign built from the public text of the original site; photos and trademarks belong to the business, so check you have permission to reuse them.
