
# Mid-Town Motel: Website Redesign

Static redesign of the Mid-Town Motel website (Boothbay Harbor, Maine).
Plain HTML, CSS and JavaScript. No build tools needed.

## Pages
Home, Rooms, About, Offers, Boothbay Guide, Location, Policies, Photo Tour

## Run locally
Open `index.html` in a browser, or run:

    python3 -m http.server 8000

## Edit content
1. Edit the data at the top of `build.py`
2. Run `python3 build.py`
3. Commit and push
